## Before and After Data Transformation

### Original Dataset
The original sales dataset contained inconsistent text values, missing entries, and data formatting issues that required preprocessing.

### Transformed Dataset
Used Power BI Power Query Editor to clean and restructure the sales data through text standardization, missing-value handling, data type corrections, column transformations, and other data-cleaning operations.

### Results
- Improved consistency of sales data.
- Standardized relevant text and data formats.
- Restructured columns for easier interpretation.
- Prepared the dataset for further analysis.

*Note: The project focuses on data cleaning and transformation. No dashboard or visualization analysis was included.*
