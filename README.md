# Sales Data Cleaning and Transformation Using Power BI

## Project Overview
This project focuses on cleaning and transforming a raw sales dataset using Microsoft Power BI and Power Query Editor. The goal was to improve data quality, resolve inconsistencies, and prepare the dataset for further analysis.

## Project Objectives
- Identify and address data quality issues in the raw sales dataset.
- Improve consistency in text values and data formats.
- Structure columns and data types appropriately.
- Prepare reliable, analysis-ready data using Power Query.

## Tools Used
- **Microsoft Power BI** — Data preparation and transformation
- **Power Query Editor** — Data cleaning and transformation operations
- **Microsoft Excel** — Original dataset format

## Data Cleaning and Transformation Steps

### 1. Duplicate Removal
Removed duplicate records to improve data consistency.

### 2. Missing Value Handling
Handled null and missing values in relevant columns.

### 3. Data Type Correction
Changed column data types to appropriate formats, such as dates and numeric values.

### 4. Column Removal and Renaming
Removed unnecessary columns and renamed fields for improved readability.

### 5. Text Cleaning and Standardization
Cleaned text values and standardized inconsistent formats.

### 6. Column Splitting and Merging
Split and merged columns to restructure the dataset and organize information.

### 7. Custom and Conditional Columns
Created custom or conditional columns to derive and organize additional information.

## Before and After
The original dataset contained inconsistent text formatting, missing entries, and irregular data values. Power Query transformations were applied to improve consistency and structure.

The transformed dataset was reviewed in Power Query Editor to prepare it for subsequent analysis.

## Project Outcome
- Improved data consistency and structure.
- Applied multiple data-cleaning and transformation techniques.
- Gained practical experience with Power Query's applied steps.
- Prepared a cleaner dataset for future analysis and visualization.
